# Design and Analysis of Algorithms (DAA)

A collection of C++ programs implementing fundamental algorithms and problem-solving techniques studied in **Design and Analysis of Algorithms (DAA)**.

This repository is intended for learning, practicing, and understanding algorithm design techniques, computational problem-solving, and time and space complexity.

## 📚 Topics Covered

### 1. Graph Algorithms
- **Bellman-Ford Algorithm** — Single-source shortest paths and negative-weight cycle detection.
- Weighted directed graph problems.

### 2. Dynamic Programming
- **Matrix Chain Multiplication** — Minimize the number of scalar multiplications.
- **Longest Common Subsequence (LCS)** — Find the longest subsequence common to two strings.
- **0/1 Knapsack** — Maximize total value subject to a weight capacity.

### 3. Backtracking
- **N-Queens Problem** — Place N queens on an N × N chessboard without conflicts.

### 4. Algorithm Analysis
- Understanding time and space complexity.
- Comparing algorithmic approaches.
- Applying suitable techniques to computational problems.

## 🛠️ Tech Stack

- **Language:** C++
- **Compiler:** GCC / G++
- **Concepts:** Graph Algorithms, Dynamic Programming, Backtracking, Recursion, Optimization

## 🚀 Getting Started

### Prerequisites

Install a C++ compiler such as GCC or G++.

Verify your installation:

```bash
g++ --version
```

### Clone the Repository

```bash
git clone https://github.com/Anshu109301/Design-And-Analysis-of-Algorithms.git
```

Navigate to the project directory:

```bash
cd Design-And-Analysis-of-Algorithms
```

### Compile and Run a Program

Navigate to the folder containing the desired C++ source file, then compile it:

```bash
g++ filename.cpp -o program
```

Run the compiled program:

**macOS / Linux**

```bash
./program
```

**Windows**

```bash
program.exe
```

Replace `filename.cpp` with the actual source filename.
